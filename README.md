| Package                                                                   | pub.dev                                                                                                                              | Description                                           |

| [apple_liquid_glass](./packages/apple_liquid_glass) | [![Pub Version](https://img.shields.io/pub/v/apple_liquid_glass)](https://pub.dev/packages/apple_liquid_glass) | iOS 27 Liquid Glass controls, bars and presentations, moving the way UIKit moves. |

| [kinesis](./packages/kinesis) | Not published | Springs, interactions and presentations that `apple_liquid_glass` moves with. |
| [liquid_glass_adaptive_brightness](./packages/liquid_glass_adaptive_brightness) | Not published | Estimates how bright the content behind a widget is, so glyphs and glass can switch between light and dark. |
